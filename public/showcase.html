How sign-in works

Discord asks permission to identify your account. DexzuBot uses your Discord ID and username to sign you in.

You can manage servers where DexzuBot is installed and you are currently a member with server ownership or Discord Administrator permission. DexzuBot checks that access for every server request.

Signing in does not add the bot to a server or request new server permissions.
